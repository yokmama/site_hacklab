WHY COMPETITIVE PROGRAMMING

速く書くより、うまく考える。

競技プログラミングは、決められた時間の中で、与えられた問題を解くプログラムを書く競技です。日本では AtCoder のコンテストが毎週のように開かれ、小学生から社会人まで参加しています。

このカリキュラムが大切にしているのは、「どう考えれば解けるか」。ぜんぶ試す、半分にしぼる、つながりをたどる、前の答えをおぼえておく。
こうした考え方の「型」を一つずつ身につけると、はじめて見る問題にも手が出せるようになります。

01

考え方の型を順番に

全探索 → 二分探索 → グラフ探索 → 動的計画法。競プロで必要になる考え方を、やさしい順に積み上げます。

02

すべてオリジナル問題

迷路、リュック、ことば探し。子どもがイメージしやすい題材で、8x9が問題から作りました。

03

コンテストへの入口

ゴールはカリキュラムの修了ではなく、AtCoder などの本番のコンテストに自分から挑戦したくなることです。

FOR PARENTS

保護者の方へ

プログラミング未経験でも大丈夫ですか？

はい。最初の11ステップで Python の基本（入力・条件分岐・ループ・リスト・関数・辞書）を学んでから、競技プログラミングの考え方に進みます。

算数・数学が得意でないと難しいですか？

算数が得意だと有利な場面はありますが、このカリキュラムで扱うのは計算力より「考え方」です。問題を小さく分けて、試して、確かめる。その積み重ねを大切にしています。

どのコースで受けられますか？

プログラミングコース（小学校高学年〜・月2回・90分）で取り組みます。どの道から始めるか、どこまで進むかは、お子さまの興味と進み具合に合わせて講師と決めていきます。まずは無料体験レッスンでご相談ください。
