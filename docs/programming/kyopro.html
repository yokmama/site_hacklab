競技プログラミング　ステップ22「大きな問題を小さく分ける（分割統治）」

大きな問題を、小さく分けて解く

数列の最大値を、左半分と右半分に分けて求めます。「分けて、解いて、合わせる」分割統治は、マージソートをはじめ多くのアルゴリズムの土台になる考え方です。

main.py
def find_max(numbers, left, right):
    # ベースケース: 要素が1個
    if left == right:
        return numbers[left]

    # 分ける
    mid = (left + right) // 2
    left_max = find_max(numbers, left, mid)
    right_max = find_max(numbers, mid + 1, right)

    # 合わせる
    if left_max > right_max:
        return left_max
    else:
        return right_max

n = int(input())
a = list(map(int, input().split()))
print(find_max(a, 0, n - 1))

FOR PARENTS

保護者の方へ

プログラミング未経験でも大丈夫ですか？

はい。最初の11ステップで Python の基本（入力・条件分岐・ループ・リスト・関数・辞書）を学んでから、競技プログラミングの考え方に進みます。

算数・数学が得意でないと難しいですか？

算数が得意だと有利な場面はありますが、このカリキュラムで扱うのは計算力より「考え方」です。問題を小さく分けて、試して、確かめる。その積み重ねを大切にしています。
