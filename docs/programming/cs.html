WHY COMPUTER SCIENCE

書き方より先に、考え方を。

プログラミング言語は、数年で流行りが変わります。けれど「問題を分解する」「手順を考える」「データを整理する」「間違いを見つけて直す」といったコンピュータサイエンスの考え方は、どの言語にも、どの時代にも通用します。

このカリキュラムは、アメリカで幼稚園から高校までの段階に合わせて整理されているコンピュータサイエンス教育（K-12）をベースに組み立てました。
思いつきで題材を並べるのではなく、何を、どの順番で身につけるかを体系立てて学びます。

01

体系的に学ぶ

順次・ループ・条件分岐・変数・関数・デバッグ。CS の基礎になる概念を、決まった順番でもれなく身につけます。

02

同じ相棒で、言語を上がる

Scratch でも JavaScript でも、動かすのは同じマイクラのペット。慣れた世界のまま、本物の言語へ進めます。

03

アルゴリズムまで届く

探索・ソート・再帰・グラフ探索、通信と暗号、エージェント。大学で学ぶような内容にも、手を動かしながらふれます。

FOR PARENTS

保護者の方へ

プログラミングがはじめてでも大丈夫ですか？

はい。最初の「ペットマスターへの道」は Scratch のブロックで進むので、キーボードでコードを書いたことがなくても始められます。ブロックで考え方を身につけてから、JavaScript に進みます。

K-12 とは何ですか？

アメリカで、幼稚園（Kindergarten）から高校3年生（12th grade）までの学校教育を指す言葉です。この段階に合わせて、コンピュータサイエンスで何を学ぶかが整理されています。8x9東京のカリキュラムは、この考え方をベースに構築しています。

どのコースで受けられますか？

プログラミングコース（小学校高学年〜・月2回・90分）で取り組みます。どの道から始めるか、どこまで進むかは、お子さまの興味と進み具合に合わせて講師と決めていきます。まずは無料体験レッスンでご相談ください。
