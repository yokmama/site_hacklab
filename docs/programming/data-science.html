WHY DATA SCIENCE

データサイエンスの「本物の流れ」を、子どものうちに。

データサイエンスは、ただグラフを描くことではありません。問いを立て、データを集め、可視化し、結論を出す。このサイクルを自分で回せることが本質です。

でも、子どもにとって「表計算ソフトの数字」は退屈です。だから 8x9東京は、子どもが夢中になれるマイクラの世界を実験場にしました。
自分で建てた農場、自分で釣った魚、自分が歩いた地形。自分ごとのデータだから、分析したくなるのです。

01

データは自分で集める

用意された表ではなく、マイクラの中でペットやプログラムを動かして、自分の手でデータを集めます。

02

プロと同じ道具

Google Colab・pandas・matplotlib など、実際のデータ分析の現場で使われている道具をそのまま使います。

03

レポートで伝える

分析して終わりではなく、グラフ付きのレポートにまとめ、最後は自分で立てた問いの答えを発表します。

保護者の方へ

Python ははじめてでも大丈夫ですか？

はい。最初のステップでは Scratch のブロックと Python の書き方を見比べながら進めます。Scratch などのブロックプログラミングの経験があると、スムーズに始められます。

数学が苦手でもついていけますか？

平均・割合・確率・座標などを扱いますが、すべてマイクラの中の具体的な題材から入ります。「数式を覚える」のではなく「データから何がわかるか」を考えることを大切にしています。

どのコースで受けられますか？

プログラミングコース（小学校高学年〜・月2回・90分）で取り組みます。どの道から始めるか、どこまで進むかは、お子さまの興味と進み具合に合わせて講師と決めていきます。まずは無料体験レッスンでご相談ください。
